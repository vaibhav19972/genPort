KMP / Kotlin Low-Code iOS / Android AI / Agentic

Senpiper (One Resource)

Sole mobile lead for the iOS and Android apps of One Resource, Senpiper's multi-tenant low-code platform for forms, workflows, and business process automation used by government, consulting, and banking clients.

The Challenge

One Resource serves demanding enterprise clients across government, consulting, and banking. The original codebases would not build locally, carried no knowledge-transfer handoff, and were riddled with workarounds, duplicated logic, and non-modular code. The form engine was driven by a deeply nested recursive JSON schema that bundled styling, dependent keys, and workflow definitions together — forcing per-client branches and parallel fixes on every platform change.

Key Contributions

  • Zero-KT Onboarding: Debugged build and environment issues with no knowledge-transfer sessions, studied the architecture from shared documentation, and got both apps running across simulators, emulators, and physical devices.
  • KMP V2 Form Architecture: Designed a Kotlin Multiplatform architecture for the new V2 form schema, moving schema parsing, the form-rendering runtime, and core logic into a single shared layer with thin native UI on each platform.
  • Codebase Unification: Audited fragmented code and drove a unification effort based on DRY and SOLID principles, eliminating workarounds and duplicated logic.
  • Form Editing Workflow: Built the form editing workflow on both iOS and Android.
  • Real-Time Filling Viewer: Built a live form-filling viewer that lets reviewers watch fields update in real time while a form is being completed.
  • Beat (from scratch): Built a police-department app for managing officer beats, leave applications, and HR services on top of the low-code form engine, using feature flags to select Beat-specific flows so one engine serves a fully separate product.
  • Multi-Tenant Customization: Redesigned the login flow, revamped the UI with a new design system and reusable token system, managed Firebase configurations per client, and customized fields, domains, slugs, and home pages per tenant.
  • Agentic AI Workflows: Built Harness agentic workflows that orchestrate Claude, Codex, and Ollama (cloud + local frontier models), wiring multiple harnesses, managing tokens, and generating automated pipelines.
  • AI-Driven Engineering: Authored orchestration methods directly from documentation to scaffold harnesses around work, keep context intact, and write ADRs to a file capturing key decisions for long-term, agent-less reuse across any AI tool and new GitHub repository.
